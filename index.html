હજુ સુધી કોઈ ગૂગલ શીટ લિંક કરેલ નથી

તમારા ગૂગલ ફોર્મ્સ જોડાયેલા હોય તે ગૂગલ પત્રકોને લિંક કરવા માટે "🔗 ફોર્મ લિંક કરો (Connect Sheets)" ટેબ પર જાઓ.

ફોર્મ / પ્રોજેક્ટ નામ (Form Title) છેલ્લી એન્ટ્રીનો સમય (Last Submission) છેલ્લાં ૨૪ કલાકની એન્ટ્રીઝ (Entries 24h) છેલ્લી વ્યક્તિનું નામ/ઈમેલ (Last Submitter) સ્થિતિ (Status) ઍક્શન (Action)

🔍 ફોર્મ વાઇઝ એન્ટ્રી લોગ (Form Submission History)

કોઈપણ ફોર્મ પસંદ કરી તેમાં થયેલી બધી જ સબમિશન એન્ટ્રીઓ જોઈ શકો છો.

ક્રમ (No) તારીખ અને સમય (Timestamp) ઓપરેટર આઈડેન્ટિટી (Email / Submitter)

🔗 નવી ગૂગલ શીટ લિંક કનેક્ટ કરો (Connect Google Sheet)

ગૂગલ ફોર્મના જવાબો જે ગૂગલ શીટમાં એક્સપોર્ટ થાય છે તે શીટની લિંક અને નામ અહીં સેવ કરો.

નોંધ: ગૂગલ શીટના શેરિંગ સેટિંગ્સમાં જઈને "Anyone with the link can view" સેટિંગ ચાલુ રાખવું જરૂરી છે.

📋 હાલમાં કનેક્ટ થયેલા લાઈવ ફોર્મ્સ (Active Connections)

ફોર્મ / પ્રોજેક્ટ નામ ફોર્મ લિંક શીટ લિંક સ્થિતિ (Sync Status) ઍક્શન

⚙️ ગૂગલ શીટ લિંક મેળવવાની સરળ રીત

  1. તમારા ગૂગલ ફોર્મના સેટિંગમાં Responses ટૅબમાં જઈને ફોર્મને ગૂગલ શીટ સાથે લિંક કરો.
  2. એ ગૂગલ શીટમાં જઈ જમણી બાજુ ઉપર **Share** બટન પર ક્લિક કરો.
  3. ત્યાં જઈને **"Anyone with the link can view"** ઓપ્શન પસંદ કરો.
  4. એ ગૂગલ શીટની લિંક કોપી કરી ડાબી બાજુએ ફોર્મ નામ સાથે પેસ્ટ કરી સેવ કરો!
